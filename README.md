# 都道府県リレー

出発の県から、となりの県だけを通って目的の県へ。いちばん少ない県の数で着けるかを競う、1日3問の地図パズル。

- 遊ぶ: https://satou-aaaaa.github.io/todofuken-relay/
- 地図の黄色い県か、下のボタンを押して、となりの県へ進みます。「ひとつ戻る」で戻れますが、進んだ回数は減りません。最短で着けば★3つ。
- 今日の3問（近場・遠出・通行止め）はだれでも同じで1日1回。上級（地図なしの2問・ヒントなし）、練習、通った県が集まる県帳があります。時間制限はありません。
- 海をこえるのは、橋とトンネルでつながる5か所だけ：青函トンネル（青森〜北海道）・関門トンネル（山口〜福岡）・明石海峡大橋と大鳴門橋（兵庫〜徳島）・瀬戸大橋（岡山〜香川）・しまなみ海道（広島〜愛媛）。沖縄県は橋やトンネルでつながっていないので出てきません。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（県の名前は入りません）。

## 地図のデータ

- 県の形は [dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson`（国土交通省「国土数値情報（行政区域データ）」をもとにしたもの）を、`tools/make-data.py` で線を間引いて `map.js` にしたものです。
- となりの県は、県境の点を共有しているかで機械的に決めています（手では書いていません）。
- 橋・トンネルは、本州四国連絡高速道路株式会社（https://www.jb-honshi.co.jp/）の3つのルートと、青函トンネル・関門トンネルです。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
python3 tools/make-data.py <japan.geojson>   # map.js を作り直すとき
```
